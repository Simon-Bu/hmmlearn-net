# HMM-4 — Hmmc forward and backward passes, scaling and log

> Forgejo issue #10 · closed · opened 2026-10-07 14:43:21 UTC by `claude` · closed 2026-10-07 15:34:08 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-4.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-4.yml)

**Objective.** Port the forward and backward passes of ext/_hmmc.cpp (the numerical core of hmmlearn) to C#: HmmLearn.Hmmc.ForwardScaling,
ForwardLog, BackwardScaling, BackwardLog and the two log helpers LogSumExp and LogAddExp. Every model uses them.
Reference: reference/hmmlearn-0.3.3/ext/_hmmc.cpp lines 9-28 (logaddexp, logsumexp), 46-138 (forward_scaling, forward_log) and
140-205 (backward_scaling, backward_log); the Wikipedia example of reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_base.py (class
TestBaseAgainstWikipedia); and the numbers of oracle/golden/hmmc.json (structure in oracle/README.md; do not open the JSON file
whole, it is large).

**Criteria**

- **C1** — Hmmc.ForwardScaling reproduces log_prob, fwdlattice and scaling of every forward_scaling expectation of oracle/golden/hmmc.json
(including the Wikipedia example, zeros in the transition matrix and a single sample), throws ArithmeticException for the cases
marked raises (an impossible observation), and ArgumentException for inconsistent shapes.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm4.ForwardScalingTests`

- **C2** — Hmmc.ForwardLog reproduces log_prob and fwdlattice of every forward_log expectation of oracle/golden/hmmc.json, including
-infinity log probabilities that must not produce NaN, and throws ArgumentException for inconsistent shapes.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm4.ForwardLogTests`

- **C3** — Hmmc.BackwardScaling and Hmmc.BackwardLog reproduce bwdlattice of every backward_scaling and backward_log expectation of
oracle/golden/hmmc.json, and throw ArgumentException for inconsistent shapes (including a scaling vector of the wrong length).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm4.BackwardTests`

- **C4** — Hmmc.LogSumExp and Hmmc.LogAddExp are stable: they give log 2 for two zeros, survive values around 1000 and -1000, return the
other argument when one is -infinity, and -infinity when all inputs are -infinity.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm4.LogSumExpTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer

**Roles.** tests: `qwen-q4-long` · coder: `qwen-pi` · reviewer: `qwen-q4-long` · 1 rounds at most

**Writable scope.** `src/HmmLearn/Hmmc.ForwardBackward.cs`

**Waiver: reviewer from the same family as the coder.** POC local-only decided by Simon
