# HMM-2 — InternalUtils - log-determinant, split by lengths, covariance checks

> Forgejo issue #4 · closed · opened 2026-10-07 12:53:44 UTC by `claude` · closed 2026-10-07 14:16:24 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-2.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-2.yml)

**Objective.** Port hmmlearn/_utils.py to C#: the static class HmmLearn.InternalUtils with LogDet, SplitXLengths, ValidateCovars and
DistributeCovarMatrixToMatchCovarianceType, used by the models and the KL divergences later.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/_utils.py (84 lines) and the numbers of oracle/golden/internal_utils.json (structure in
oracle/README.md; do not open the JSON file whole, it is large). There is no Python test file for these helpers.

**Criteria**

- **C1** — InternalUtils.LogDet returns log |det| of a square matrix (NaN for a negative determinant, -infinity for a singular matrix) and
rejects a matrix that is not square. Every case of logdet_cases of oracle/golden/internal_utils.json is reproduced.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm2.LogDetTests`

- **C2** — InternalUtils.SplitXLengths splits by lengths (null lengths gives x itself) and rejects negative lengths or lengths that do not sum
to the number of rows. Every case of split_lengths_cases is reproduced.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm2.SplitXLengthsTests`

- **C3** — InternalUtils.ValidateCovars accepts valid compact covariances of the four types and throws ArgumentException exactly when
hmmlearn raises ValueError (non-positive variances, not symmetric, not positive definite) or the shape is wrong. Every case of
validate_covars_cases is reproduced.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm2.ValidateCovarsTests`

- **C4** — InternalUtils.DistributeCovarMatrixToMatchCovarianceType creates the compact covariances of the four types, in the uniform
shapes. Every case of distribute_covar_cases is reproduced.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm2.DistributeCovarMatrixTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
