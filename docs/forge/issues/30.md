# HMM-11 — MultinomialHmm - hidden Markov model with multinomial emissions

> Forgejo issue #30 · closed · opened 2026-10-07 20:40:31 UTC by `claude` · closed 2026-10-07 21:28:49 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-11.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-11.yml)

**Objective.** Port MultinomialHMM of hmmlearn/hmm.py and BaseMultinomialHMM of hmmlearn/_emissions.py to C#: HmmLearn.MultinomialHmm (derived from
BaseHmm). Observations are vectors of counts; the total of a sample is its number of trials. It reuses CategoricalStatistics
(merged with CategoricalHmm).
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/hmm.py lines 812-943 (MultinomialHMM) and
reference/hmmlearn-0.3.3/src/hmmlearn/_emissions.py lines 310-369 (BaseMultinomialHMM); its tests
reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_multinomial_hmm.py; and the numbers of oracle/golden/multinomial.json (structure in
oracle/README.md; do not open the JSON file whole, it is large).

**Criteria**

- **C1** — Score, ScoreSamples, Decode (Viterbi and Map), Predict and PredictProba reproduce every inference case of
oracle/golden/multinomial.json with both implementations (fixed trials, one trial equal to the categorical example, totals that vary
per sample).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm11.InferenceParityTests`

- **C2** — Fit reproduces the parameters, the history, the iteration count, the convergence flag, the score, aic and bic of every fit case of
oracle/golden/multinomial.json with both implementations (all parameters, emission only, totals that vary).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm11.FitParityTests`

- **C3** — Invalid input and parameters are rejected with ArgumentException: an EmissionProb that is null, of the wrong shape or with rows
that do not sum to 1; counts that are fractional or negative; a sample whose total differs from NTrials when it has a value;
a different number of columns than a previous fit; Sample without NTrials throws InvalidOperationException.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm11.ValidationTests`

- **C4** — Sample returns count vectors that total NTrials and whose mean per state matches NTrials times EmissionProb (statistically);
with random initialization (InitParams "ste", fixed RandomState) Fit starts from valid distributions, is reproducible, and the log
likelihood never decreases from one single-iteration Fit to the next on sampled data.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm11.SamplingAndFitTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
