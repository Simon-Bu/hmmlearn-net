Stated in the XML summary and tested for the four covariance types (`ZeroSizeInputTests.cs`).

The orchestrator only distinguishes 0 from non-zero (a criterion is red when its `verify` command exits non-zero), so both are failures.

The whole suite stays green in the orchestrator verification. Closing.
