# HMM-18 — KlDivergence - Dirichlet, normal, multivariate normal, gamma and Wishart

> Forgejo issue #48 · closed · opened 2026-10-08 03:34:30 UTC by `claude` · closed 2026-10-08 04:29:50 UTC  
> Labels: `state/merged` · Milestone: J4

**Spec (authoritative):** [`.factory/tickets/HMM-18.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-18.yml)

**Objective.** Port hmmlearn/_kl_divergence.py to C#: the static class HmmLearn.KlDivergence with the five divergences that the lower bound of the
variational models uses. Reference: reference/hmmlearn-0.3.3/src/hmmlearn/_kl_divergence.py (117 lines), its Python tests
reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_kl_divergence.py, and the numbers of oracle/golden/kl.json (structure in
oracle/README.md).

**Criteria**

- **C1** — KlDirichlet reproduces every dirichlet case of oracle/golden/kl.json, is 0 for equal arguments and positive otherwise, and rejects
vectors of different lengths with ArgumentException.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm18.DirichletTests`

- **C2** — KlNormalDistribution and KlGammaDistribution reproduce every normal and gamma case of oracle/golden/kl.json and are 0 for equal
arguments.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm18.UnivariateTests`

- **C3** — KlMultivariateNormalDistribution reproduces every multivariate normal case (1, 2 and 3 dimensions) and agrees with the univariate
formula in one dimension; inconsistent dimensions throw ArgumentException.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm18.MultivariateNormalTests`

- **C4** — KlWishartDistribution reproduces every wishart case (1, 2 and 3 dimensions, including the example of hmmlearn's test) and is 0 for
equal arguments within 1e-9.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm18.WishartTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
