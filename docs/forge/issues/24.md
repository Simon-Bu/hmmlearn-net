# HMM-9 — BaseHmm - priors, initialization, M-step, checks, stationary distribution, AIC and BIC

> Forgejo issue #24 · closed · opened 2026-10-07 19:14:31 UTC by `claude` · closed 2026-10-07 19:53:03 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-9.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-9.yml)

**Objective.** Port BaseHMM of hmmlearn/base.py to C#: the abstract class HmmLearn.BaseHmm (derived from AbstractHmm) with the Dirichlet priors of
the start probabilities and transition matrix, their random initialization, their validation, their M-step, the stationary
distribution and the AIC and BIC criteria. With the EM loop of AbstractHmm it makes the EM of the start probabilities and the
transition matrix work; emission models (categorical, Gaussian...) come in later tickets.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/base.py lines 781-977 (BaseHMM: __init__, get_stationary_distribution, _do_mstep,
_compute_lower_bound, _init, _check_sum_1, _check) and 979-1025 (aic, bic); its tests reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_base.py
(test_base_hmm_attributes, test_stationary_distribution); and the numbers of oracle/golden/base.json (fit_cases) and
oracle/golden/stationary.json (structure in oracle/README.md; do not open the JSON files whole, they are large).

**Criteria**

- **C1** — Check accepts valid StartProb and TransMat and throws ArgumentException when StartProb is null, has the wrong length or does not
sum to 1, and when TransMat is null, has the wrong shape or a row that does not sum to 1; Score on a model with invalid parameters
fails the same way.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm9.CheckTests`

- **C2** — Fit with explicit initial parameters reproduces startprob, transmat, history, n_iter_done, converged, score, aic and bic of every
fit case of oracle/golden/base.json with both implementations (priors, the s, t and st parameter sets, structural zeros of a
left-to-right model, sequences of length 1, a single iteration).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm9.FitParityTests`

- **C3** — Init draws valid random distributions only for the parameters that must be initialized, reproducibly for a given RandomState,
leaves explicit parameters alone when InitParams does not name them, and raises the two warnings (parameter set although
InitParams names it; fewer data values than free parameters).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm9.InitTests`

- **C4** — GetStationaryDistribution reproduces every case of oracle/golden/stationary.json (it sums to 1 and is invariant under TransMat) and
throws InvalidOperationException when TransMat is null; Aic and Bic equal -2 * Score + 2 * k and -2 * Score + k * ln(rows) with k the
sum of GetNFitScalarsPerParam(), and match the aic and bic of the fit cases.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm9.StationaryAndCriteriaTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
