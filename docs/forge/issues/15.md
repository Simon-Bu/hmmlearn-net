# HMM-6 — ConvergenceMonitor

> Forgejo issue #15 · closed · opened 2026-10-07 16:12:40 UTC by `claude` · closed 2026-10-07 17:23:31 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-6.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-6.yml)

**Objective.** Port ConvergenceMonitor of hmmlearn/base.py (lines 21-126) to C#: HmmLearn.ConvergenceMonitor, which the EM loop of every model
uses to record log probabilities, report them and decide when to stop.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/base.py lines 21-126, its Python tests reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_base.py
(class TestMonitor), and the numbers of oracle/golden/monitor.json (structure in oracle/README.md).

**Criteria**

- **C1** — After each Report of every scenario of oracle/golden/monitor.json, Converged, Iter and History equal the expected steps
(convergence by iteration count, by improvement below the tolerance, by a decrease; never converged).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm6.ConvergenceTests`

- **C2** — With verbose true the monitor writes exactly the lines of stderr_lines of every scenario to the given TextWriter (including the
"+nan" of the first line and the alignment); with verbose false it writes nothing.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm6.VerboseOutputTests`

- **C3** — Reset empties the history and sets Iter to 0; the Warning event is raised exactly when a report is lower than the previous one by
more than about 1.49e-8 (not for an improvement, not for a tiny decrease); a subclass can override Converged.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm6.ResetAndWarningTests`

- **C4** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer

**Roles.** tests: `qwen-q4-long` · coder: `qwen-pi` · reviewer: `qwen-q4-long` · 1 rounds at most

**Writable scope.** `src/HmmLearn/ConvergenceMonitor.cs`
