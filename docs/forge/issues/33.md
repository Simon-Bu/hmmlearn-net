# HMM-12 — KMeans - minimal deterministic Lloyd algorithm

> Forgejo issue #33 · closed · opened 2026-10-07 21:29:14 UTC by `claude` · closed 2026-10-07 21:56:35 UTC  
> Labels: `state/merged` · Milestone: J2

**Spec (authoritative):** [`.factory/tickets/HMM-12.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-12.yml)

**Objective.** Write HmmLearn.KMeans, a minimal deterministic k-means (Lloyd's algorithm) used by the default initializations of the Gaussian,
mixture and variational Gaussian models (hmmlearn uses scikit-learn's KMeans there; the port does not need to reproduce its results,
only to find sensible clusters, deterministically). There is no Python reference file and no oracle: the tests are structural and
statistical. The specification is the XML comment of the stub src/HmmLearn/KMeans.cs.

**Criteria**

- **C1** — On data made of three or four well separated blobs, KMeans.Fit puts the samples of each blob in the same cluster and the samples of
different blobs in different clusters, and its centers are close to the blob means (partitions compared, not label numbers).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm12.SeparatedClustersTests`

- **C2** — At the end each center is the mean of the samples that carry its label, each sample is at least as close to its own center as to
any other, the result is deterministic (same input, same output), and x is left untouched.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm12.LloydInvariantsTests`

- **C3** — Edge cases: k = 1 gives the mean of the data; k = n gives every sample its own center when the samples are distinct; duplicate
points do not break the algorithm; maxIter = 0 returns the farthest-point seeds; a center left without samples is recovered; invalid
arguments throw ArgumentException.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm12.EdgeCaseTests`

- **C4** — The code stays readable: short methods, no dead code, the XML summary matches the behaviour. · judged by the reviewer
