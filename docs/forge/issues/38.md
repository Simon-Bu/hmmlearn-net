# HMM-14 — GaussianHmm learning - initialization, M-step with priors, information criteria

> Forgejo issue #38 · closed · opened 2026-10-07 23:23:19 UTC by `claude` · closed 2026-10-08 00:25:13 UTC  
> Labels: `state/merged` · Milestone: J2

**Spec (authoritative):** [`.factory/tickets/HMM-14.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-14.yml)

**Objective.** Port the learning half of GaussianHMM of hmmlearn/hmm.py to C#: Init (k-means for the means, the data covariance for the
covariances) and DoMStep (means and covariances with Normal and inverse-Wishart style priors, for the four covariance types) in
src/HmmLearn/GaussianHmm.Learning.cs, the second file of the partial class GaussianHmm. With it GaussianHmm fits end to end.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/hmm.py lines 307-322 (_init) and 340-388 (_do_mstep); its tests
reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_gaussian_hmm.py; and the numbers of oracle/golden/gaussian_spherical.json,
gaussian_diag.json, gaussian_tied.json and gaussian_full.json (fit_cases; structure in oracle/README.md; do not open the JSON
files whole, they are large). The first half (parameters, checks, likelihood, sampling, statistics) is already merged.

**Criteria**

- **C1** — Fit with explicit initial parameters reproduces the start probabilities, transition matrix, means, covariances (compact), history,
iteration count, convergence flag, score, aic and bic of every fit case of the four oracle files with both implementations (priors,
parameter subsets, structural zeros, sequences of length 1, a single tied or full matrix with the scalar prior added to every entry).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm14.FitParityTests`

- **C2** — Init gives the means (k-means centers) and covariances (data covariance plus MinCovar, distributed to the covariance type) only for
the letters of InitParams that need it, is reproducible, leaves explicit parameters alone when InitParams does not name them, and
raises the "will be overwritten" warning when a set parameter is re-initialized.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm14.InitTests`

- **C3** — On data sampled from a model with well separated means, fitting from the random initialization recovers means and covariances close
to the true ones for the four covariance types, never decreases the log likelihood from one single-iteration Fit to the next, and
Aic and Bic equal -2 * Score + 2 * k and -2 * Score + k * ln(rows) with k the documented number of free parameters.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm14.LearningTests`

- **C4** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
