# HMM-15 — PoissonHmm - hidden Markov model with Poisson emissions

> Forgejo issue #41 · closed · opened 2026-10-08 00:26:15 UTC by `claude` · closed 2026-10-08 00:56:50 UTC  
> Labels: `state/merged` · Milestone: J3

**Spec (authoritative):** [`.factory/tickets/HMM-15.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-15.yml)

**Objective.** Port PoissonHMM of hmmlearn/hmm.py and BasePoissonHMM of hmmlearn/_emissions.py to C#: HmmLearn.PoissonHmm (derived from BaseHmm)
and PoissonStatistics. Observations are vectors of counts; the features are independent given the state.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/hmm.py lines 945-1075 (PoissonHMM) and
reference/hmmlearn-0.3.3/src/hmmlearn/_emissions.py lines 372-410 (BasePoissonHMM); its tests
reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_poisson_hmm.py; and the numbers of oracle/golden/poisson.json (structure in
oracle/README.md; do not open the JSON file whole).

**Criteria**

- **C1** — Score, ScoreSamples, Decode (Viterbi and Map), Predict and PredictProba reproduce every inference case of oracle/golden/poisson.json
with both implementations (several sequences, zero counts).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm15.InferenceParityTests`

- **C2** — Fit reproduces the parameters, the history, the iteration count, the convergence flag, the score, aic and bic of every fit case of
oracle/golden/poisson.json with both implementations (defaults, tight tolerance, rates only, and the gamma prior that uses the
total posterior mass).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm15.FitParityTests`

- **C3** — Invalid input and parameters are rejected with ArgumentException: Lambdas null, of the wrong shape, or not positive where the
likelihood needs it; fractional or negative counts; a different number of columns than the model has features.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm15.ValidationTests`

- **C4** — Sample returns counts whose per-state mean matches Lambdas (statistically); with random initialization (InitParams "stl", fixed
RandomState) Fit starts from valid positive rates, is reproducible, and the log likelihood never decreases from one
single-iteration Fit to the next on sampled data.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm15.SamplingAndFitTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
