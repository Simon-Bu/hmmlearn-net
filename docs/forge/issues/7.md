# HMM-3 — Stats - log multivariate normal density for the four covariance types

> Forgejo issue #7 · closed · opened 2026-10-07 14:17:49 UTC by `claude` · closed 2026-10-07 14:41:28 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-3.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-3.yml)

**Objective.** Port hmmlearn/stats.py to C#: HmmLearn.Stats.LogMultivariateNormalDensity, the Gaussian emission likelihood used by the Gaussian
and mixture models later. Reference: reference/hmmlearn-0.3.3/src/hmmlearn/stats.py (98 lines) and the numbers of
oracle/golden/stats.json (structure in oracle/README.md; do not open the JSON file whole). There is no Python test file for it.

**Criteria**

- **C1** — LogMultivariateNormalDensity gives the log density for the spherical and diag covariance types, including the floor on the
variances (a zero variance at the mean) and the -infinity overflow case. Every spherical and diag case of oracle/golden/stats.json
is reproduced.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm3.SphericalDiagDensityTests`

- **C2** — LogMultivariateNormalDensity gives the log density for the full and tied covariance types through a Cholesky factor, retries
once with 1e-7 on the diagonal when the matrix is singular, and throws ArgumentException when it is still not positive definite.
Every full and tied case of oracle/golden/stats.json is reproduced (cases with raises: true expect the exception).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm3.FullTiedDensityTests`

- **C3** — A covariance array of the wrong shape for its type, or x with a different number of features than the means, throws
ArgumentException (hand-written cases).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm3.ShapeChecksTests`

- **C4** — The code stays readable: short methods, no dead code, the XML summary matches the behaviour. · judged by the reviewer

**Writable scope.** `src/HmmLearn/Stats.cs`
