# HMM-7 — AbstractHmm inference - score, decode, predict and sample

> Forgejo issue #18 · closed · opened 2026-10-07 17:24:16 UTC by `claude` · closed 2026-10-07 18:03:43 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-7.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-7.yml)

**Objective.** Port the inference half of _AbstractHMM of hmmlearn/base.py to C#: the abstract class HmmLearn.AbstractHmm with its parameters,
the hooks that the models override (Check, ComputeLogLikelihood, ComputeLikelihood, GenerateSampleFromState) and Score,
ScoreSamples, Decode, Predict, PredictProba and Sample. The fitting half (Fit, E-step, sufficient statistics) is another ticket
(AbstractHmm.Fit.cs, same partial class); here nothing fits.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/base.py lines 129-398 (the constructor, score_samples, score, _score, _score_log,
_score_scaling, _decode_viterbi, _decode_map, decode, predict, predict_proba, sample) and 508-521 (_compute_posteriors_scaling and
_compute_posteriors_log); its tests reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_base.py (StubHMM, TestBaseAgainstWikipedia,
TestBaseConsistentWithGMM); and the numbers of oracle/golden/base.json (structure in oracle/README.md; do not open the JSON file
whole, it is large). Already merged and usable: Hmmc (forward, backward, Viterbi), Utils.Normalize and LogNormalize,
InternalUtils.SplitXLengths, ConvergenceMonitor.

**Criteria**

- **C1** — Score, ScoreSamples and PredictProba reproduce score, log_prob and posteriors of every inference case of oracle/golden/base.json
with both implementations (several sequences through lengths included), and fail with InvalidOperationException when StartProb is
null, ArgumentException for lengths that do not sum to the number of samples and for empty or non-finite observations.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm7.ScoringTests`

- **C2** — Decode and Predict reproduce viterbi and map (log_prob and states) of every inference case with both implementations; Decode with
no algorithm uses the Algorithm property; Predict equals the states of Decode.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm7.DecodingTests`

- **C3** — Sample returns nSamples observations and states with the right shapes, draws states from StartProb and TransMat (frequencies
within statistical tolerance), honours currState and the Random argument or RandomState seed (same seed, same sample), and throws
ArgumentOutOfRangeException for nSamples below 1 or a currState out of range.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm7.SamplingTests`

- **C4** — The constructor stores its arguments in the properties and creates Monitor with the same tolerance, iteration count and
verbosity; RaiseWarning reaches the Warning subscribers; ComputeLikelihood defaults to the exponential of ComputeLogLikelihood;
the internal helpers ComputePosteriorsScaling and ComputePosteriorsLog (used by the fit half later) give normalized posteriors
that agree with each other on lattices of the same sequence.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm7.ConstructionTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
