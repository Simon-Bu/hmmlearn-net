# HMM-10 — CategoricalHmm - hidden Markov model with categorical emissions

> Forgejo issue #27 · closed · opened 2026-10-07 19:54:01 UTC by `claude` · closed 2026-10-07 20:40:05 UTC  
> Labels: `state/merged` · Milestone: J1

**Spec (authoritative):** [`.factory/tickets/HMM-10.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-10.yml)

**Objective.** Port CategoricalHMM of hmmlearn/hmm.py and BaseCategoricalHMM of hmmlearn/_emissions.py to C#: HmmLearn.CategoricalHmm (derived from
BaseHmm) and the shared helper HmmLearn.CategoricalEmission (internal, reused later by the variational categorical model). It is the
first complete model: Fit, Score, ScoreSamples, Decode, Predict, PredictProba, Sample, Aic, Bic all work end to end.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/hmm.py lines 26-155 (CategoricalHMM) and
reference/hmmlearn-0.3.3/src/hmmlearn/_emissions.py lines 30-109 (BaseCategoricalHMM); its tests
reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_categorical_hmm.py; and the numbers of oracle/golden/categorical.json (structure in
oracle/README.md; do not open the JSON file whole, it is large).

**Criteria**

- **C1** — Score, ScoreSamples, Decode (Viterbi and Map), Predict and PredictProba reproduce every inference case of
oracle/golden/categorical.json with both implementations (including the Wikipedia rainy and sunny example, several sequences
and a model with zeros).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm10.InferenceParityTests`

- **C2** — Fit reproduces the parameters, the history, the iteration count, the convergence flag, the score, aic and bic of every fit case of
oracle/golden/categorical.json with both implementations (priors above and below 1, parameter subsets, a left-to-right model that
keeps its zeros, sequences of length 1, an explicit n_features larger than the largest symbol).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm10.FitParityTests`

- **C3** — Invalid input and parameters are rejected with ArgumentException: an EmissionProb that is null, of the wrong shape or with rows
that do not sum to 1; observations with a fractional or negative value, with a symbol above NFeatures - 1, or with more than one
column; the number of features is inferred (largest symbol plus 1) or respected when given.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm10.ValidationTests`

- **C4** — Sample returns symbols in 0..NFeatures-1 whose frequencies match EmissionProb (statistically, all symbols appear); with random
initialization (InitParams "ste", fixed RandomState) Fit starts from valid distributions, is reproducible, and the log likelihood
never decreases from one single-iteration Fit to the next on sampled data.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm10.SamplingAndFitTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
