# HMM-24 — Stats - state and lock the null, shape and zero-size contracts of the log density

> Forgejo issue #63 · closed · opened 2026-10-08 10:15:13 UTC by `claude` · closed 2026-10-08 10:20:53 UTC  
> Labels: `state/merged` · Milestone: J5

**Spec (authoritative):** [`.factory/tickets/HMM-24.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-24.yml)

**Objective.** Close follow-up issue #9 (questions Q1 and Q2 of the review of HMM-3). Stats.LogMultivariateNormalDensity (src/HmmLearn/Stats.cs, merged)
already behaves as the questions hope: the pilot ran each case below on the merged code. Nothing writes it down and nothing locks it. This
ticket states the contracts in the XML summary and locks them with acceptance tests, for the four covariance types:
1. A null x, means or covars throws ArgumentNullException (the .NET convention). Every shape violation (x with another number of columns
   than the means, covars whose shape does not match the covariance type, nComponents and nFeatures) keeps throwing ArgumentException.
2. x with 0 rows gives an empty (0, nComponents) matrix. means with 0 rows (no component) give an (n_samples, 0) matrix. x with 0 features
   gives an (n_samples, nComponents) matrix whose entries are 0 (the log density in dimension 0 is log 1). No exception in these cases.
If a combination does not behave as stated, that is a real finding: fix the code minimally and say so in the summary of your report.
Question Q3 of the issue (the exit code of the test runner inside the agents' sandbox) needs no change: the orchestrator treats any
non-zero exit code as a failure. The coder writes the tests of this ticket (no separate tests agent).

**Criteria**

- **C1** — A null x, means or covars throws ArgumentNullException (exact type) for each of the four covariance types, and a shape violation
still throws ArgumentException (exact type).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm24.NullArgumentTests`

- **C2** — For each covariance type: x with 0 rows gives an empty (0, nComponents) result, means with 0 rows give an (n_samples, 0) result, and
x with 0 features gives an (n_samples, nComponents) result of zeros, without any exception.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm24.ZeroSizeInputTests`

- **C3** — The XML summary of LogMultivariateNormalDensity states the null and zero-size contracts; the tests are meaningful (each asserts the
contract, no tautology) and readable; the code of Stats.cs is unchanged for valid inputs.
 · judged by the reviewer
