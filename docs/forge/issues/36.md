# HMM-13 — GaussianHmm - parameters, checks, likelihood, sampling and statistics

> Forgejo issue #36 · closed · opened 2026-10-07 21:57:00 UTC by `claude` · closed 2026-10-07 23:22:35 UTC  
> Labels: `state/merged` · Milestone: J2

**Spec (authoritative):** [`.factory/tickets/HMM-13.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-13.yml)

**Objective.** Port the first half of GaussianHMM of hmmlearn/hmm.py and BaseGaussianHMM of hmmlearn/_emissions.py to C#: the partial class
HmmLearn.GaussianHmm (derived from BaseHmm) with its parameters, the compact covariance storage, the checks, the likelihood, the
sampling and the sufficient statistics of the E-step, plus GaussianStatistics and the shared helper GaussianEmission (internal,
reused later by the variational Gaussian model). The initialization and the M-step (second file of the class) come in the next ticket,
so here a model is used with explicit parameters (InitParams = "") and cannot yet learn means and covariances.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/hmm.py lines 158-338 (GaussianHMM: constructor, covars_ property, _check,
_needs_sufficient_statistics_for_mean and _for_covars) and reference/hmmlearn-0.3.3/src/hmmlearn/_emissions.py lines 112-181
(BaseGaussianHMM); its tests reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_gaussian_hmm.py; and the numbers of
oracle/golden/gaussian_spherical.json, gaussian_diag.json, gaussian_tied.json and gaussian_full.json (inference_cases; structure in
oracle/README.md; do not open the JSON files whole, they are large).

**Criteria**

- **C1** — Score, ScoreSamples, Decode (Viterbi and Map), Predict and PredictProba reproduce every inference case of the four oracle files
(spherical, diag, tied, full covariances) with both implementations, several sequences and a length-1 sequence included.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm13.InferenceParityTests`

- **C2** — The Covars setter rejects invalid compact covariances (wrong shape for the type, non-positive variances, a matrix that is not
symmetric positive definite) with ArgumentException and stores a copy of a valid one; Check rejects missing or mis-shaped Means or
Covars and a Covars whose number of features differs from that of Means; FullCovars gives (nc, nf, nf) matrices for the four types,
correct for spherical covariances with several features.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm13.ValidationTests`

- **C3** — Sample returns observations of the right shape whose per-state mean and covariance match Means and FullCovars (statistically), for
the four covariance types, and the first state follows StartProb.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm13.SamplingTests`

- **C4** — After an E-step the statistics given to DoMStep hold Post, Obs and Obs2 (spherical, diag) or ObsObsT (full, tied) equal to the
weighted sums computed in the test from the posteriors, only for the letters in Params ('m' and 'c' as described), and
GaussianEmission.NFitScalars gives the documented counts for the four types.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm13.StatisticsTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer

**Roles.** tests: `qwen-q4-long` · coder: `qwen-pi` · reviewer: `qwen-q4-long` · 1 rounds at most

**Writable scope.** `src/HmmLearn/GaussianHmm.cs`, `src/HmmLearn/GaussianEmission.cs`

**Waiver: reviewer from the same family as the coder.** POC local-only decided by Simon
