# HMM-17 — GmmHmm learning - initialization with k-means and M-step with priors

> Forgejo issue #46 · closed · opened 2026-10-08 02:41:00 UTC by `claude` · closed 2026-10-08 03:32:59 UTC  
> Labels: `state/merged` · Milestone: J3

**Spec (authoritative):** [`.factory/tickets/HMM-17.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-17.yml)

**Objective.** Port the learning half of GMMHMM of hmmlearn/hmm.py to C#: Init (k-means for the states, then for the mixture components of each
state; the data covariance for the covariances) and DoMStep (mixture weights, means and covariances with priors, for the four
covariance types) in src/HmmLearn/GmmHmm.Learning.cs, the second file of the partial class GmmHmm. With it GmmHmm fits end to end.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/hmm.py lines 533-591 (_init), 593-648 (_init_covar_priors, _fix_priors_shape: the
defaults are in GmmHmm.EffectiveCovarsPrior and EffectiveCovarsWeight) and 734-809 (_do_mstep); its tests
reference/hmmlearn-0.3.3/src/hmmlearn/tests/test_gmm_hmm.py, test_gmm_hmm_multisequence.py and test_gmm_hmm_new.py; and the numbers
of oracle/golden/gmm_spherical.json, gmm_diag.json, gmm_tied.json and gmm_full.json (fit_cases; structure in oracle/README.md; do not
open the JSON files whole, they are large). The first half (parameters, checks, likelihood, sampling, statistics) is already merged.

**Criteria**

- **C1** — Fit with explicit initial parameters reproduces the start probabilities, transition matrix, weights, means, covariances (compact
rank 4), history, iteration count, convergence flag, score, aic and bic of every fit case of the four oracle files with both
implementations (defaults, tight tolerance, parameter subsets w, m, c, explicit priors including the scalar covariance prior).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm17.FitParityTests`

- **C2** — Init sets Weights to 1 / NMix, Means from the two-level k-means, and Covars from the data covariance in the shape of the covariance
type, only for the letters of InitParams that need it; it is reproducible for a RandomState, handles a cluster with fewer samples
than NMix, and leaves explicit parameters alone when InitParams does not name them.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm17.InitTests`

- **C3** — On data sampled from a mixture model with well separated components, fitting from the random initialization yields valid parameters
(weights rows sum to 1, covariances accepted by Check), never decreases the log likelihood from one single-iteration Fit to the
next, and Aic and Bic equal -2 * Score + 2 * k and -2 * Score + k * ln(rows) with k the documented number of free parameters.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm17.LearningTests`

- **C4** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
