# HMM-19 — VariationalBaseHmm - Dirichlet posteriors, subnormalized E-step, M-step and lower bound

> Forgejo issue #51 · closed · opened 2026-10-08 04:30:48 UTC by `claude` · closed 2026-10-08 05:13:22 UTC  
> Labels: `state/merged` · Milestone: J4

**Spec (authoritative):** [`.factory/tickets/HMM-19.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-19.yml)

**Objective.** Port VariationalBaseHMM of hmmlearn/base.py to C#: the abstract class HmmLearn.VariationalBaseHmm (derived from AbstractHmm) with the
Dirichlet priors and posteriors of the start probabilities and of each transition row, their random initialization, their validation,
the subnormalized parameters of the E-step (digamma), the M-step and the variational lower bound. With the EM loop of AbstractHmm and
the KL divergences of KlDivergence it makes the variational fit of the start probabilities and the transition matrix work; the
variational emission models come in later tickets.
Reference: reference/hmmlearn-0.3.3/src/hmmlearn/base.py lines 1031-1272 (VariationalBaseHMM), reference/hmmlearn-0.3.3/src/hmmlearn/tests
(test_variational_categorical.py and test_variational_gaussian.py show how it is used), and the numbers of oracle/golden/variational_base.json
(structure in oracle/README.md; do not open the JSON files whole, they are large).

**Criteria**

- **C1** — Check accepts valid priors and posteriors and throws ArgumentException when one of the four arrays is null or has the wrong length
or shape; Fit and Score on a model with invalid parameters fail the same way.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm19.CheckTests`

- **C2** — Fit with explicit initial parameters reproduces startprob_posterior, transmat_posterior, startprob, transmat, history, n_iter_done,
converged and score of every fit case of oracle/golden/variational_base.json with both implementations (the s, t and st parameter
sets, strong priors, sequences of length 1, a few and many iterations).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm19.FitParityTests`

- **C3** — Init draws valid random Dirichlet posteriors with the documented scaling only for the parameters that must be initialized,
reproducibly for a given RandomState, fills the priors from the scalar priors or 1 / NComponents, leaves explicit parameters alone
when InitParams does not name them, and raises the two warnings (parameter set although InitParams names it; fewer data values
than free parameters).
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm19.InitTests`

- **C4** — EstepBegin computes the subnormalized start probabilities and transition rows with digamma (positive, below 1, summing to less
than 1), DoMStep adds the statistics to the priors and normalizes the posteriors into StartProb and TransMat (only for the letters
of Params), and ComputeLowerBound equals the log probability minus the KL divergences of the posteriors from the priors.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm19.SubnormAndBoundTests`

- **C5** — The code stays readable: short methods, no dead code, the XML summaries match the behaviour. · judged by the reviewer
