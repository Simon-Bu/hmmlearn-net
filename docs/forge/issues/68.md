# HMM-26 — BaseHmm - stationary distribution when it is not unique

> Forgejo issue #68 · closed · opened 2026-10-08 10:33:40 UTC by `claude` · closed 2026-10-08 10:37:06 UTC  
> Labels: `state/merged` · Milestone: J5

**Spec (authoritative):** [`.factory/tickets/HMM-26.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-26.yml)

**Objective.** Fix the gap that the review of HMM-9 left open (follow-up issue #26) in src/HmmLearn/BaseHmm.cs, which is merged. GetStationaryDistribution
solves (P^T - I) pi = 0 with a normalization row in place of the last equation. When the transition matrix has several closed classes
(the identity, two absorbing states, two disconnected cycles, two ergodic blocks) the stationary distribution is not unique, the system is
singular and MathNet's LU returns NaN entries: the pilot saw [NaN, NaN, NaN] for the 3x3 identity and [NaN, NaN, 0] for two absorbing states
and a transient state. hmmlearn (base.py get_stationary_distribution: scipy.linalg.eig, the eigenvector of the first eigenvalue of largest
real part) returns a valid distribution there, so the port must too.
Rule. When the stationary distribution is unique, nothing changes (same code path, same numbers). When it is not, the result is the
stationary distribution of the closed class that holds the lowest state index among the closed classes (a closed class is a set of states that
reach each other and that no transition leaves), and 0 for every state outside that class. The four non_unique_cases of
oracle/golden/stationary.json, computed by hmmlearn 0.3.3 itself, all follow this rule.
The coder writes the tests of this ticket and then the fix (no separate tests agent).

**Criteria**

- **C1** — For every entry of non_unique_cases of oracle/golden/stationary.json, GetStationaryDistribution returns the oracle values, with no NaN, no
negative entry, a sum of 1 and pi * TransMat = pi; the periodic unique matrix [[0,1],[1,0]] gives [0.5, 0.5]; TransMat is left unchanged.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm26.NonUniqueStationaryTests`

- **C2** — A unique stationary distribution is computed exactly as before (the existing cases of oracle/golden/stationary.json and the tests of HMM-9
stay green) and the new tests are meaningful: at least one fails on the unfixed code and passes on the fix (the reviewer checks this against
the diff and the coder's summary); no test re-implements the code under test.
 · judged by the reviewer

- **C3** — The XML summary of GetStationaryDistribution states the rule for the non-unique case; the code stays readable: short methods, no dead code. · judged by the reviewer

**Roles.** coder: `sonnet-5.5` · reviewer: `gpt-sol-6.1` · 2 rounds at most

**Writable scope.** `src/HmmLearn/BaseHmm.cs`, `tests/acceptance/HMM-26/**`
