# HMM-25 — Hmmc - ComputeLogXiSum on a sequence without samples

> Forgejo issue #65 · closed · opened 2026-10-08 10:21:04 UTC by `claude` · closed 2026-10-08 10:33:24 UTC  
> Labels: `state/merged` · Milestone: J5

**Spec (authoritative):** [`.factory/tickets/HMM-25.yml`](https://github.com/Simon-Bu/hmmlearn-net/blob/main/.factory/tickets/HMM-25.yml)

**Objective.** Fix the inconsistency that the review of HMM-5 left open (follow-up issue #14) in src/HmmLearn/Hmmc.ViterbiXi.cs, which is merged. For
consistently empty input (fwdlattice, bwdlattice and the frame probabilities all (0, nc), transmat (nc, nc), i.e. n_samples = 0):
- ComputeScalingXiSum already runs its documented empty loop and returns the neutral matrix of zeros;
- ComputeLogXiSum reads fwdlattice[n_samples - 1, 0], that is row -1, and throws an undocumented IndexOutOfRangeException.
The C++ reference has undefined behavior at that spot. The documented sum runs over t = 0..n_samples-2, which is empty for 0 samples as
it is for 1 sample, so ComputeLogXiSum returns its neutral matrix too: an (nc, nc) matrix of -infinity, exactly what it returns for one
sample. The coder writes the tests of this ticket and then the fix (no separate tests agent).

**Criteria**

- **C1** — ComputeLogXiSum with 0 samples returns a new (nc, nc) matrix of -infinity (nc = 1, 2, 3) and does not throw; ComputeScalingXiSum with
0 samples returns an (nc, nc) matrix of zeros; shape errors on 0 samples still throw ArgumentException.
 · `dotnet run --project tests/HmmLearn.Tests -- --filter-class HmmLearn.Tests.Acceptance.Hmm25.ZeroSampleXiSumTests`

- **C2** — The new tests are meaningful: at least one fails on the unfixed code and passes on the fix (the reviewer checks this against the diff and
the coder's summary), and no test re-implements the code under test.
 · judged by the reviewer

- **C3** — The XML summary of ComputeLogXiSum states the 0-sample result; the code stays readable: short methods, no dead code. · judged by the reviewer

**Roles.** coder: `sonnet-5.5` · reviewer: `gpt-sol-6.1` · 2 rounds at most

**Writable scope.** `src/HmmLearn/Hmmc.ViterbiXi.cs`, `tests/acceptance/HMM-25/**`

_Published by the pilot. The ticket's state is carried by the `state/…` labels, updated by the orchestrator._
