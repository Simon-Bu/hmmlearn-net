Each override matches the reference semantics (Dirichlet emission init scaled by (sum of lengths)/NComponents with scalar prior or 1/NFeatures; digamma-based subnormalized E-step term; M-step posterior = prior + Obs with row-normalized EmissionProb as new arrays; lower bound = base - sum of per-row Dirichlet KL; Check with the two documented error messages; NFeatures inference; GetNFitScalarsPerParam null until NFeatures is known, per pilot Q1). The base-class conventions the locked tests rely on (CDF draws = first index with cdf > u with last-index fallback, documented Sample draw order, log-space Viterbi over ComputeLogLikelihood) match the test-side reimplementations exactly; the pilot-fixed Viterbi helper (first candidate includes log(transMat[0,j]), separate next-delta array) is present in the checked-in EmissionTests.cs. The golden file's five fit cases cover every C1 category (ste, ste few iterations, te, st, unit sequences); null expected values (startprob/score without 's', emissionprob/score without 'e') are asserted null and skipped exactly as the locked tests document. All constraints hold: only src/HmmLearn/VariationalCategoricalHmm.cs changed, no new packages, no base-class members added, all signatures and XML summaries kept, caller arrays never mutated (new arrays in Init and DoMStep, verified by the NotSame/no-mutation test). Working tree is clean; the other diffs vs main are the tests agent's four mandated acceptance files and the pilot's ticket update (max_rounds 2), which are process artifacts, not code-scope violations. All listed acceptance-test assumptions were checked against the code: no gaps found. No remarks.

After a fixed-seed Fit, Score, Decode (Viterbi) and Sample match test-side reimplementations (log-space forward with log-sum-exp, standard log-space Viterbi, CDF draws in the documented order with the identical 'first cdf > u, last index if none' convention) computed from the model's own StartProb, TransMat and EmissionProb; Sample with the same seed 99 on both sides matches exactly. | C4 | satisfied | BehaviourTests rerun by me: 7/7 pass.
