**Remarks**
- **R1** (minor) `src/HmmLearn/BaseHmm.cs:138` — For a transition matrix whose stationary distribution is NOT unique - e.g. the identity matrix, or two absorbing states - the system (P^T - I) with the normalization row is still rank-deficient, and MathNet's LU().Solve then returns NaN entries instead of throwing: I probed MathNet 5.0.0 (net48 build) in memory, solving [[0,0],[1,1]] (exactly the system built from the 2x2 identity transmat) against [0,1], and it returned [NaN, NaN]. GetStationaryDistribution would therefore return an all-NaN vector that does not sum to 1, while the reference linalg.eig returns an eigenvector of the eigenspace (e.g. [1, 0, ..., 0] for the identity). None of the four golden stationary cases hit this (they all have a unique stationary distribution), and no criterion pins it, so this is a minor gap, not a criterion violation; it also means the XML summary's 'normalized to sum 1' does not hold on those inputs. Expected: Either fall back to the eigendecomposition of the transposed matrix (as in the reference) when the linear system is singular/NaN, or explicitly state in the XML summary that the transition matrix must have a unique stationary distribution. No test change is required; the locked acceptance tests are sufficient for the ticket's criteria.
