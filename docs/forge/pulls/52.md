Round 1 review of HMM-19. Pilot waiver applies (reviewer shares the coder's model family), so every criterion was verified independently against the reference (hmmlearn 0.3.3 base.py VariationalBaseHMM, lines 1031-1272) and every verify command was run as written. src/HmmLearn/VariationalBaseHmm.cs (273 lines) matches the reference: Init fills the prior values unconditionally when a NeedsInit block fires and draws the posteriors from the uniform 1/NComponents Dirichlet alpha scaled by the number of sequences (startprob) or total length / NComponents per row (transmat), using one Random (new Random(RandomState) or Random.Shared) shared by both blocks, the short-circuited NeedsInit or-semantics and the exact BaseHmm degenerate-solution warning (free scalars counted over the letters of Params, strictly-less threshold); Check validates null/length/shape only, with the four documented ArgumentException messages, and is reached by both Fit and Score; EstepBegin refreshes both subnorm arrays as exp(DiGamma(p) - DiGamma(sum p)) without touching the posteriors; the four Fit* hooks route the E-step to the subnormalized parameters and subnormalized emission likelihoods; DoMStep replaces the posteriors with prior + stats and normalizes them into StartProb/TransMat as new arrays, only for the letters of Params, never mutating caller or stats arrays; ComputeLowerBound is currLogProb minus the Dirichlet KL of the start posterior and of each transmat row posterior from their priors. Verify results (orchestrator, this commit): all four filtered verify commands passed; reviewer rerun of the full suite: CheckTests 18/18, FitParityTests 11/11 (every fit case of oracle/golden/variational_base.json under Log and Scaling, plus the caller-array no-mutation test), InitTests 12/12 (including the pilot-fixed init_counts_the_free_parameters_of_the_letters_in_params_only: 1x1 data warns, 2x1 does not), SubnormAndBoundTests 8/8, full suite 1031/1031, exit code 0. Scope is clean: the diff against main touches only the ticket file (pilot's max_rounds change), src/HmmLearn/VariationalBaseHmm.cs and the four locked acceptance test files, nothing in AbstractHmm or elsewhere; the StubVariationalHmm helper lives inside FitParityTests.cs as the pilot accepted. No constraints are violated: only MathNet.Numerics and the BCL are used, signatures and XML summaries are intact, no array a caller passes is mutated. One minor remark (R1): the golden file has no params-'s'-only fit case, so the s-only direction of C2's parenthetical is covered in isolation by the M-step letter test rather than by a golden fit; it is a coverage observation, not a defect, and C2 as written is met.
