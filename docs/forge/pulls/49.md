- **R1** (minor) `tests/acceptance/HMM-18/MultivariateNormalTests.cs:84` — The covariance-related exception tests do not isolate the covariance checks: kl_multivariate_normal_rejects_covariances_of_different_sizes and kl_multivariate_normal_rejects_a_mean_inconsistent_with_its_covariance both pass inconsistent mean lengths (3 vs 2 and 1 vs 2), so the mean-length check at KlDivergence.cs:55 fires before any covariance check. Consequently no locked test exercises a square-but-wrong-size covarQ or covarP, or a non-square covarP, with consistent means. The code implements all of these checks (KlDivergence.cs:57-60) and I verified the logic by inspection, so C3 is met; this is a locked-test sufficiency observation only. (The Wishart 2x2 vs 3x3 test is properly isolated by comparison.) Expected: Full isolation would need, e.g., a test with means of length 2, covarQ 2x2, covarP 3x3, and one with covarP 2x3, each expecting ArgumentException. The tests are locked, so no action is required in this ticket; noted for the pilot in case later tickets extend the suite.
